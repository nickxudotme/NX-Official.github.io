Gin 入门笔记（十）Cookie 与 Session
初识 Cookie HTTP 是无状态协议。简单地说，当你浏览了一个页面，然后转到同一个网站的另一个页 面，服务器无法认识到这是同一个浏览器在访问同一个网站。每一次的访问，都是没有任何关系的。如果我们要实现多个页面之间共享数据的话我们就可以使用 Cookie 或者 Session 实现 cookie 存储于访问者计算机的浏览器中，可以让我们用同一个浏览器访问同一个域名的时候共享数据 Cookie 能实现的简单功能： 保持用户登录状态 保存用户浏览记录 使用 Cookie 设置 Cookie 1con.SetCookie(name string, value string, maxAge int, path string, domain string, secure bool, httpOnly bool) maxAge：过期时间 大于0，设置过期时间，单位为秒 小于0，删除本Cookie 等于0，设置为当关闭浏览器时过期 path：Cookie的路径 domain：作用域，若要在多个二级域名中使用，如a.example.com和b.example.com，则要写成.example.com secure：为True时，仅在HTTPS中生效 httpOnly：用于防止客户端脚本通过document.cookie属性访问Cookie，有助于保护Cookie不被跨站脚本攻击窃取或篡改 读取 Cookie 1cookie, err := con.Cookie("name") 样例 defaultRouters.go 1...
