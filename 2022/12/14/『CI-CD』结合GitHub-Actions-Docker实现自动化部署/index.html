发表于2022-12-14|更新于2025-11-08|运维CICD
|总字数:1.9k|阅读时长:7分钟

上一篇 『CI/CD』使用GitHub Actions实现简单的自动化部署 中实现了简单的自动化部署，本篇来介绍一下使用 docker 的做法 （NX 整整折腾了两天呢）

基本流程

首先要明确一下最终的运行流程，一共有4个步骤

  1. 更新代码，提交至GitHub
  2. GitHub 触发 Actions，自动 build 镜像，并推送至镜像仓库
  3. 服务器拉取最新镜像
  4. 重新启动容器
